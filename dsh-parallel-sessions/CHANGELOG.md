# Changelog

## 0.4.0

- 显示名改为「会话状态 / Session Status」（原「并行会话」）：侧栏入口、面板标题、插件列表元信息同步更新。包名与 slot id 不变。
- 包元信息补齐：license、author、repository、homepage、keywords；新增 LICENSE、CHANGELOG、.gitignore。

## 0.3.0

- 每行在色点后增加状态文字（固定 58px 对齐）：待审批 / 待回答 / 计划待审 / 已完成未看 / 运行中 / 空闲，不再只靠颜色区分。
- 状态词带中文兜底，语言词典缺失时也不会丢字。

## 0.2.0

- 状态按优先级着色：待审批(红) / 待回答(橙) / 计划待审(紫) / 已完成未看(蓝) / 运行中(绿，脉冲) / 空闲(灰)。
- 排序改为「该不该现在看」优先，同级按最后活跃时间；项目分组同样规则。
- 顶部汇总「等你处理 N · 运行中 M · 共 T」，新增「只看需要我处理」过滤。

## 0.1.0

- 首个版本：左侧栏「并行会话」入口 + 跨项目会话总览，点击直达会话。
