# Changelog

## v0.3.1 (2026-10-26)

- **看过即清除**：点进会议详情看过内容后，侧栏的「已结束 / 已总结 / 脑图已生成」提示自动熄灭（未读语义）；已看过的会议记入 localStorage，刷新页面后不再复读。新的会议（不同 id）会重新点亮
- **一键沉淀**：详情页新增「沉淀归档」——
  - 「存入知识库」：纪要全文直写本地 WeKnora（手工知识接口，status=publish 自动建索引），需在插件配置里填 `weknoraBaseUrl / weknoraApiKey / weknoraKnowledgeBaseId`（本机在 profile patch 里配置，密钥不进包源码）
  - 「存入记忆」：摘要+决议+待办写入 mneme（`POST /api/dsh-mneme/create`，type=project），同名自动去重合并
  - 目标可用性自动探测（WeKnora 由宿主探测并缓存 60s；记忆由页面探同源 `/api/dsh-mneme/health`）：**没装对应插件就显示「尚未安装」，不会报错**
  - 未生成纪要时提示先生成；宿主新增 `GET /integrations`、`POST /save` 接口
- **文案兜底**：长驻页面 + 插件热重载时，locale 服务里的词典可能停留在旧版本（同名空间首次注册优先），新增文案会原样显示成英文 key；所有文案查找已加「自带词典兜底」，任何情况下不再出现裸 key。遇到英文 key 刷新一次页面即可彻底恢复
- **纪要 prompt 适配说话人分离**：转写带「说话人N：」标签时，明确要求纪要把待办 owner 写成对应说话人、讨论/决议标注提出者。A/B 实测（同一份转写带/不带标签各生成一次）：带标签的待办负责人 100% 归属正确（说话人1/2），不带标签的 LLM 会**编造看似合理的角色**（如「前端负责人」——实际是发言者同时负责后端），错误归属比「未明确」更有害

## v0.3.0 (2026-10-26)

三个核心改进：转写不中断、全流程状态标识、会后说话人分离。

- **转写不再中断**：麦克风收音从面板组件改为页面级单例，切换到其他会话/面板不再停止收音；只有「结束会议」或宿主判定会议结束时才停。插件热重载时自动接管仍在运行的旧实例，不会出现双重上送或必须手动重连
- **状态标识**：侧栏「会议模式」图标圆点 + 行内文字胶囊 + 面板标题徽标 + 历史列表彩色标签，覆盖全流程：连接中 / 转写中 / 收尾中 / 异常 / **已结束**（待出纪要）/ **已总结**（待出脑图）/ **脑图已生成**（全部完成）。侧栏自己轮询（进行中 1.5s、空闲 6s，只取状态不取句子），主面板轮询到的快照立即同步
- **说话人分离（会后，可选）**：录制时把 PCM 按序落盘，结束会议时收尾成 `音频.wav`；详情页一键「区分发言人」→ 上传百炼临时存储 → 离线 `paraformer-v2` + `diarization_enabled` 重跑整段录音 → 按毫秒时间区间重叠把 speaker 回填到实时句子 → 重写 `转写全文.txt`（`[mm:ss] 说话人1：…`）。费用约 0.29 元/小时（无分离附加费），通常 1-5 分钟；历史列表与详情页显示说话人清单，重新生成纪要会带上说话人
- **生成流程拆分**：「生成会议纪要」只出 md/docx（状态 → 已总结），「生成脑图」用已存大纲本地渲染（状态 → 脑图已生成，不花额外 LLM 调用）；两步各自可重做，重出纪要会让旧脑图过期并提示重出
- 宿主接口：新增 `POST /mindmap`、`POST /diarize`、`GET /meetings?brief=1`；`GET /state?id=` 支持宿主重启后从磁盘恢复历史会议；`meta.json` 增加 `speakers/diarized/sentenceTimes`
- ⚠️ 需要重启 DSH 才能让宿主半边生效（客户端半边刷新页面即可）

## v0.2.0 (2026-10-26)

左侧栏运行状态指示（一眼看出会议还在不在转写）：

- 左侧栏「会议模式」图标右下角加状态圆点：绿=转写中、琥珀=连接中/收尾中、红=异常；圆点带呼吸动画
- 左侧栏该行右侧加文字胶囊（`转写中` / `连接中` / `收尾中` / `异常`），侧栏收起成图标轨道时不显示文字，避免撑破 36px 行
- 悬停图标显示完整提示：`会议模式 · 转写中 · 会议标题 · 05:12`
- 状态由客户端小型 store 共享：主面板轮询到的状态立即同步到侧栏；面板没打开或切到别的会话时，侧栏图标自己轮询 `/state`（只取状态、不取句子，轮询开销不随会议变长而变大）
- 面板标题行加同色状态徽标（`● 转写中 05:12`），原静态提示文案在录制中改为「正在实时转写，请正常开会」

## v0.1.2 (2026-10-25)

交互修复与优化：

- 修复：会议详情页「返回」按钮原先埋在页面最底部（脑图与转写预览之后），几乎不可见，导致进入纪要后无法返回列表；改为顶部粘性导航条（← 返回 + 会议标题），滚动到任意位置都能返回
- 详情页/错误页支持 ESC 键返回；进入详情自动滚回面板顶部
- 历史会议列表整行可点击（原来只能点「打开」小按钮）
- 纪要正文（摘要/决议/待办）随 meta.json 持久化，历史会议点开即见纪要内容，不再只有下载链接（旧会议点一次「重新生成」即可补上）
- 生成纪要成功后自动刷新历史列表状态

首次公开发布。

- 实时转写：浏览器麦克风 → 16k PCM → DSH Host → 阿里云百炼 `qwen-audio-3.1-asr-flash-streaming`（run-task WebSocket 协议），面板实时滚动显示

- markmap 交互式脑图 HTML（浏览器直接打开，可打印成 PDF）
- 历史会议回看，宿主重启后可从落盘转写全文补生成纪要
- 会议记录落盘：`转写全文.txt`、`会议纪要.md`、`会议纪要.docx`、`脑图.html`、`meta.json`
