# Changelog

## 0.1.4 — 2026-10-18

- 修正位置：运行中的 DSH 把「用量」和「时间」包在同一个 inline-flex 容器（`endInfo`）里，插件条目只能在它之前或之后，0.1.3 的 `order` 只能把费用排到时间之后。现用 `display:contents` 把这层容器摊平进行内的 flex 流，再按 `order` 把「本轮 ¥x.xxxx」排到「用量 xxx tok」之后、时间之前。
- 若 DSH 后续改了容器/时间元素的类名，会退化为默认位置（分支图标前），不影响金额与弹窗。

## 0.1.3 — 2026-10-18

- 位置调整：操作行内用 CSS `order` 把「本轮 ¥x.xxxx」排到「用量 xxx tok」之后、时间之前（DSH 的操作行固定为 复制 → 插件动作 → 分支 → 用量 → 时间，插件动作默认只能在分支之前）。若 DSH 后续改了时间元素的类名，会退化为排在时间之后，不影响显示。

## 0.1.2 — 2026-10-18

- 修复操作行内的「本轮 ¥x.xxxx」不显示：assistant 行的 Chat node kind 是 `assistant-step`，之前按 `assistant` 匹配导致查不到对应轮次而返回空。现在改为按消息 id（`finalNode.messageId`）匹配，不再依赖 kind 名称。
- 位置、弹窗、金额口径不变。

## 0.1.1 — 2026-10-18

- 本轮费用从「对话底部独立一行」移到**操作行内**（`conversation.chat.assistant-actions`），紧挨着「用量 xxx tok」，和 token 用量并排显示；不再额外占一行。
- 明细弹窗、金额口径不变。

## 0.1.0 — 2026-10-18

首个公开发布版本。

- 输入框下方新增「累计 ¥x.xxxx」：整个会话的费用（跨轮次、跨模型、按高峰/空闲分档）。
- 每轮对话 footer 新增「本轮 ¥x.xxxx」。
- 两处均可点开明细弹窗，观感与 token 用量弹窗一致（贴触发点向上、`dl` 明细行、点外部/Esc 关闭）。
- 宿主侧新增 `llmCostTokens` 会话投影：按 `provider/model` 把整条日志折成高峰/空闲两组 token 桶，长会话分页不漏算。
- 内置 2026-10 官网单价：DeepSeek-Flash、DeepSeek-V4-Pro、GLM-5.3、GLM-5.3-Flash；`-free` 模型按 0。
- 内置 2026 年中国法定节假日表（33 天），节假日全天按空闲时段计。
- 金额保留 4 位小数；子代理独立会话不计入。
